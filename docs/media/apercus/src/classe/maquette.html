  • Filtres : PvE / PvP, spé (Toute la classe + les 3), origine (Classic, adaptée de Classic, nouvelle dans Forever). Compteurs à côté.
  • Texte de la macro : les noms anglais du site sont remplacés par ceux de ton client (ID de sort relevé hors ligne, nom lu par le jeu). Les sorts en jaune.
  • Créer : CreateMacro, hors combat seulement, dans le personnage (18 places) ou le compte (120) ; grisé avec la raison si c'est plein. Icône « ? » : le #showtooltip montre le sort.
  • Mettre à jour : Questify retient les macros qu'il a créées (nom + texte). Si le site change la macro ou si tu l'as supprimée, le bouton le dit ; une macro que tu as modifiée à la main est signalée avant d'être écrasée.
  • Nom de la macro dans le jeu : 16 caractères au plus, préfixe « QF » (ex. « QF Nova recul »).
